# Max Car

Responsive website for direct car imports from Japan and the United Kingdom.

## Preview

Open `index.html` in a browser, or serve this directory with any static web server.

## Features

- Japan and UK market sections
- Filterable model inspiration
- Import process guide and FAQs
- Enquiry builder with copy-to-clipboard support
- Responsive layouts and reduced-motion support

The enquiry form generates a message locally. It does not send or store enquiries. Business contact details must be added before connecting direct enquiries. Vehicles and photography are illustrative, not live inventory. Images and fonts load from external services.

## Files

- `index.html`: page content
- `style.css`: styles
- `app.js`: market filters and enquiry builder

No installation or build step is required.
